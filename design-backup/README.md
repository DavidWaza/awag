# Design backup — original forest-green/ivory theme

`original/` holds pristine copies of every file changed by the black & gold
"Noir Edition" redesign (July 2026). Nothing else was modified.

## To revert to the original design

Either run:

```powershell
powershell -ExecutionPolicy Bypass -File design-backup/restore-original-design.ps1
```

…or ask Claude Code to "revert to the original design".

Once you are sure you are keeping one of the two designs, this folder can be
deleted.
